# Data Center Cable Planner

Sistema visual para planejamento de racks, calhas e metragem de cabos em data centers.

## Rodar localmente

Abra `index.html` em um navegador moderno. Não é necessário Python ou Flask.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `app.js`, `app.css` e este `README.md`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

O Excel usa a biblioteca SheetJS carregada por CDN no navegador.
